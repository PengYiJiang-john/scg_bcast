# Historical source-access summary: recovered provenance

This CSV is preserved byte-for-byte from the user-supplied experiment archive. At first, that archive supplied only means, counts, and references to two older PDFs. During the 2026-09-26 audit, the underlying H22 traces and direct judge records were recovered from the author's separate local project.

The complete selected records, an offline audit script, and a description of remaining metadata gaps are now in `../archive/source_access/`. All four rounded means match reaggregation from 120 raw `models/gemini-2.5-pro` judge responses joined to their workflow terminal texts. Each condition's reported `n=30` is five base cases times six prescribed workflows; it is not thirty independent cases or replications.

The variable is descriptive false-semantic adoption intensity. It is not error probability, a counterfactual effect, or a behavior allocation. The exact generation model and runtime metadata were not persisted in the recovered traces. Source-score `ci_low`/`ci_high` fields are placeholders, not confidence intervals. The E1–E3 BCAST comparisons remain unexecuted.
